## Коротко

Сервис распределяет заявки между выездными инженерами с учётом квалификации,
оборудования, транспорта и временных окон, строит маршруты по реальным дорогам
OpenStreetMap, автоматически перепланирует день при новых событиях и объясняет
каждое своё решение.

На данных заказчика за 17.08.2026 (территория Восток, 66 заявок, 12 бригад):
**все 66 заявок в срок восемью бригадами и 251 км пробега** против 63 заявок,
двенадцати бригад и 282 км у живого диспетчера.

Разворачивается локально: Docker не нужен, внешних платных API нет, дорожный
граф и кеш геокодера лежат в репозитории.
