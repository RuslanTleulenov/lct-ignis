# ЛЦТ 2026 — проекты хакатона

Монорепозиторий-песочница: один каталог = один кейс. Ничего не пересекается,
можно параллельно вести несколько задач.

## Проекты

| Каталог | Кейс | Статус |
|---|---|---|
| [`route-planner/`](route-planner/) | Интеллектуальный сервис планирования рабочих маршрутов для инженеров с учётом временных окон и сложности работ | 🟡 проектирование |
| [`heat-network/`](heat-network/) | Сервис моделирования трассировки тепловых сетей для технологического присоединения новых зданий | 🟢 данные и расчётное ядро |
| [`slide-designer/`](slide-designer/) | Цифровой дизайнер презентаций: разбор шаблона и автоматическая вёрстка презентации по тексту | 🟢 веб-интерфейс, API и CLI, нормоконтроль по рендеру |

## Соглашения

- Каждый проект самодостаточен: свой README, свои зависимости, свой `docs/`.
- Документы — в `docs/`, нумерованные (`01-`, `02-`, …), на русском.
- Данные (в т.ч. синтетические) — в `data/`, генератор рядом, чтобы датасет
  воспроизводился одной командой.
- Ветки: `main` — рабочая, фичи — `feat/<проект>-<что>`.
